# ПОС — Руководство пользователя

## 1. Введение

Данное руководство описывает порядок работы с консольным приложением ПОС.

Система предназначена для управления студентами, рубрикаторами, критериями оценивания, выставления оценок, формирования итоговых результатов и экспорта отчётов.

## 2. Запуск приложения

Для запуска приложения необходимо перейти в корневую директорию проекта и выполнить команду:

```bash
dotnet run --project src/Pos.Cli
```

После запуска отображается главное меню:

1. Управление студентами.
2. Управление рубрикаторами.
3. Управление оценками.
4. Отчёты и результаты.

Для завершения работы необходимо выбрать `0`.

## 3. Управление студентами

В разделе управления студентами доступны следующие операции:

- Просмотр списка студентов.
- Добавление нового студента.
- Удаление студента.

### Добавление студента

1. Открыть раздел «Управление студентами».
2. Выбрать добавление студента.
3. Ввести полное имя студента.
4. После успешного выполнения операции система создаст студента с уникальным идентификатором.

### Просмотр студентов

При выборе просмотра списка отображаются зарегистрированные студенты и их идентификаторы.

### Удаление студента

1. Выбрать операцию удаления.
2. Выбрать нужного студента из списка.
3. Подтвердить удаление.

## 4. Управление рубрикаторами

В разделе управления рубрикаторами доступны:

- Просмотр всех рубрикаторов.
- Создание рубрикатора.
- Добавление критерия.
- Просмотр критериев.
- Удаление рубрикатора.
- Удаление критерия.

### Создание рубрикатора

1. Открыть раздел «Управление рубрикаторами».
2. Выбрать создание рубрикатора.
3. Система создаст новый рубрикатор с уникальным идентификатором.

После создания рубрикатор не содержит критериев.

### Добавление критерия

1. Выбрать операцию добавления критерия.
2. Выбрать рубрикатор.
3. Ввести название критерия.
4. Указать максимальный балл.
5. Указать вес критерия.

Критерий характеризуется тремя основными параметрами:

- Название.
- Максимальный балл.
- Вес.

Максимальный балл должен быть больше нуля.

Вес должен быть больше нуля и не превышать единицу.

### Просмотр критериев

При выборе рубрикатора система отображает список его критериев:

- Название.
- Максимальный балл.
- Вес.

Также отображается суммарный вес критериев.

### Удаление критерия

1. Выбрать удаление критерия.
2. Выбрать соответствующий рубрикатор.
3. Выбрать критерий.
4. Подтвердить удаление.

Критерий, по которому уже выставлены оценки, удалить нельзя.

### Удаление рубрикатора

1. Выбрать удаление рубрикатора.
2. Выбрать нужный рубрикатор.
3. Подтвердить удаление.

Рубрикатор, по которому уже выставлены оценки, удалить нельзя.

## 5. Управление оценками

Раздел управления оценками предназначен для работы с результатами студентов.

Доступные операции:

- Выставление оценок.
- Просмотр выставленных оценок.
- Изменение оценок.
- Отмена оценок.

### Выставление оценки

Для создания оценки необходимо:

1. Открыть раздел «Управление оценками».
2. Выбрать студента.
3. Выбрать рубрикатор.
4. Выбрать критерий.
5. Ввести количество баллов.
6. Подтвердить операцию.

Система проверяет корректность введённой оценки.

Выставленный балл не может быть отрицательным или превышать максимальный балл критерия.

Также невозможно выставить оценку по критерию, который не принадлежит выбранному рубрикатору.

### Просмотр оценок

Пользователь может выбрать студента и просмотреть его выставленные оценки.

### Изменение оценки

1. Выбрать операцию изменения оценки.
2. Найти соответствующую оценку.
3. Ввести новое количество баллов.

После изменения система проверяет корректность нового значения.

### Отмена оценки

1. Выбрать операцию отмены оценки.
2. Выбрать нужную оценку.
3. Подтвердить отмену.

После отмены оценка удаляется из данных приложения.

## 6. Отчёты и результаты

Раздел предназначен для просмотра итоговых результатов студентов и экспорта отчётности.

Доступны две операции:

1. Просмотреть отчёт студента.
2. Экспортировать отчёт.

### Просмотр отчёта

Для формирования отчёта необходимо:

1. Открыть раздел «Отчёты и результаты».
2. Выбрать просмотр отчёта студента.
3. Выбрать студента.
4. Выбрать рубрикатор.

После этого система формирует отчёт, содержащий:

- Имя студента.
- Идентификатор студента.
- Идентификатор рубрикатора.
- Список критериев.
- Максимальные баллы.
- Веса критериев.
- Выставленные оценки.
- Итоговую оценку.

Если по выбранному рубрикатору ещё нет критериев, система сообщает об этом.

Если оценки отсутствуют, итоговая оценка не рассчитывается.

### Экспорт отчёта

Для экспорта необходимо:

1. Выбрать экспорт отчёта.
2. Выбрать студента.
3. Выбрать рубрикатор.
4. Выбрать формат экспорта.
5. Указать путь сохранения файла.

Поддерживаемые форматы:

**CSV**

Предназначен для работы с табличными данными и может открываться в электронных таблицах.

**JSON**

Предназначен для структурированного хранения данных и последующей программной обработки.

Примеры путей сохранения:

```text
data/report.csv
data/report.json
```

После успешного экспорта система выводит сообщение о сохранении файла и его путь.

## 7. Обработка пользовательского ввода

Приложение проверяет корректность пользовательского ввода.

Проверяются:

- Допустимость выбранного пункта меню.
- Корректность числовых значений.
- Допустимые границы оценок.
- Корректность весов критериев.
- Наличие обязательных текстовых значений.

При некорректном вводе система сообщает об ошибке и предлагает повторить ввод.

### Отмена операций

В предусмотренных меню для отмены используется значение `0`.

Оно позволяет отказаться от текущей операции и вернуться к предыдущему меню.

Операции удаления требуют дополнительного подтверждения.

## 8. Хранение данных

Данные приложения хранятся в JSON-файлах:

| Файл | Назначение |
|---|---|
| students.json | Сведения о студентах |
| rubrics.json | Рубрикаторы и критерии |
| evaluations.json | Выставленные оценки |

Основная директория хранения данных — `data`.

После завершения работы приложения сохранённая информация остаётся доступной при следующем запуске.

## 9. Завершение работы

Для завершения работы необходимо вернуться в главное меню и выбрать пункт `0`.

Приложение выведет сообщение о завершении работы и закроется.
